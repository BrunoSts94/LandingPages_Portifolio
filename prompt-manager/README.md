## 📋 Prompt manager
Projeto de umgerenciador de prompts
## 🧐 Sobre
Projeto desenvolvido durante um evento Fullstack da Rocketseat, nesse projeto podemos adicionar, editar, deletar e pesquisar prompts salvos. Foi usado o metodo de salvamento em local storage mas podendo ser migrado para um banco de dados facilmente. 
Nessa experiencia pude aprofundar meus conhecimentos em lógica dom javascript, e também uso da ia do copilot para agilizar o processo de desenvolvimento.
## 🤖🛠️ Tecnologias e ferramentas utilizadas
- HTML5
- CSS3
- Javascript
- Microsoft Copilot
