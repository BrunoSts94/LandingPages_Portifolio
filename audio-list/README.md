## 📋 Audio List
Projeto de uma página onde podemos tocar musica atrvás da interação do usuario com um painel de comando
## 🧐 Sobre
Projeto desenvolvido para aprimorar e aplicar novos conhecimentos em Javascript e lógica de programação, aqui foi criada uma logica para troca de musica, play, e pause conforme o usuario interage, também são trocados os textos da tela e executado um novo son a cada interação. Utilizei como tema para esse projeto um dos meus jogos preferidos, o Expedition 33.
## 🤖🛠️ Tecnologias e ferramentas utilizadas
- HTML5
- Tailwind CSS
- Javascript
